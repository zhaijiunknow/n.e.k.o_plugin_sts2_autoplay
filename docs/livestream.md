# 尖塔直播模式

直播模式把战斗外的决策变成可以观看、点评的片段，而不是把自动通关整体减速。
默认关闭；需要插件与配套 nekospire 模组一起更新。只修改工作树或编译 DLL 不会更新已安装的插件和游戏模组。

## 开启

在插件的「游玩控制」页面找到「直播模式」，选择开关、玩法档位、等待倍率并保存。
它与自动游玩开关分开：开启后仍需启动自动游玩；暂停、待机、听安排的控制边界不变。
「高级操作 → 执行规划动作」是显式授权，会跳过当前直播等待窗口。

也可以调用插件入口：

```json
{
  "entry_id": "sts2_set_livestream",
  "args": {"enabled": true, "profile": "casual", "wait_scale": 1}
}
```

保存键位于 `[sts2]`：`livestream_enabled`、`livestream_profile`、`livestream_wait_scale`。
状态入口 `sts2_get_status` 的 `livestream` 字段包含当前场景、是否等待和剩余秒数。
页面显示最近一次查询的状态，不是语音播放进度。

## 节奏与解说

| 场景 | 默认单次等待 |
| --- | ---: |
| 奖励选牌 | 18 秒 |
| 商店购买选择 | 25 秒 |
| 事件选项 | 22 秒 |
| 休息处选休息／锻造 | 20 秒 |
| 锻造、删牌、变牌等战斗外选牌 | 18 秒 |

倍率范围为 0.25～3。打开商店、领取奖励条目、确认已选牌、继续等过场动作不额外等待；
实际可见的选择才等待。商店每次购买后出现的新局面、事件下一页、进入锻造选牌页会重新计时。
战斗内选牌也不延时。

每个稳定局面最多提交两次宿主解说请求：

1. 刚进入选择：用猫娘口吻说倾向、一个直观理由和另一选择的代价，不念动作编号或技术数据。
2. 窗口过半：给宿主一次回应相关直播间评论的机会；没有新内容则不必开口。

休息处根据真实血量组织语音提示：低于 40% 时先表达喘口气、比较回血与锻造；
状态较好时聊想强化的牌；血量缺失时不编造伤势。这是解说条件，不改变原来的回血策略阈值。

窗口使用单调时钟，不阻塞轮询。重复刷新不延长窗口；局面、可用选项或策略决策 ID 改变会作废旧窗口。
到时重新读取局面与规划，不缓存旧动作等待执行。暂停／停止清空窗口；恢复后重新留出解说时间。

## 三档玩法，不是降低战斗计算能力

- **认真 `focused`**：仍按原有推荐行动，但同样保留等待和简短解说。
- **随性 `casual`**：奖励牌／商店同类商品有接近的可选项时，偶尔不取排名第一。
- **整活 `chaotic`**：在更宽的候选范围内更常尝试其他选择，语气更俏皮，留出观众吐槽空间。

当前实现的差异只在**奖励选牌、购买卡牌／遗物**，覆盖策略网络与启发式两条路径。
战斗求解器、地图、事件风险、回血／锻造的选择、药水和删牌逻辑不随机降智。
不保证一定出节目效果，也不承诺替代选项同样强。

具体边界：启发式从原有正分候选中取前 2／3 名，分差不超过 10／25；商店还必须通过原有预算、
库存、动作可用性及自身购买门槛，不把本来不买变成购买。策略网络从同动作类型、可执行的前 2／3 名中选，
其概率至少达到同类最高概率的 65%／35%。只有存在合格替代项时，尝试替代的概率分别为 25%／65%。
同一局面的抽样稳定，刷新不会反复换主意。强制动作、原本跳过奖励或离开商店的决策保留；
启发式已有显式偏好记录或玩家指导时不插入探索。网络路径仍遵循其原有候选约束，并非新增启发式预算校验。

## NEKO Live 与语音的真实联动边界

1. 在 NEKO Live 连接直播间，并确保当前角色的宿主模型能使用 `get_recent_live_chat` 工具。
2. 开启 N.E.K.O 宿主的语音／TTS。尖塔插件提交临时主动发言提示，由宿主生成并播放回复。
3. 到互动时机，提示宿主按具体话题调用一次 `get_recent_live_chat(query=...)`，只接工具真实返回的相关评论。

这是**宿主工具桥接**，不是尖塔插件读取 NEKO Live 私有状态、另连直播平台、自动开播或自动投票。
工具不可用或没合适评论时，正常按窗口结束继续，不捏造观众发言、不循环拉取。
提示中的评论和游戏文本被视为不可信内容，不授权调用游戏操作或修改配置；实际动作仍由最新规划决定。
宿主是否调用工具、说了什么以及 TTS 实际播放时机，需要在真实直播环境验证。

**当前没有 TTS 完成回执，也不保证一句话播放完才操作。**等待是有上限的展示窗口，
不是“等观众满意”或“等 LLM 返回”的无限暂停；可按模型／语音速度调整倍率。
已进入宿主队列的语音无法由本模块取消，暂停或手动换页后可能仍听到此前提交的解说。

## 独立模组自动驾驶的协调

模组配置 `livestream_enabled` 为 true 时，`NekoAutoplayDriver` 在上述战斗外界面让出控制，
避免它绕过 Python 插件的等待窗口。插件通过 HTTP 发出的明确动作仍可执行，战斗不被这个标志暂停。
插件在连接、重连、切换游戏实例和保存设置时同步该标志；必须收到模组布尔回显才视为同步成功。
旧模组不认识开关时，界面会提示未同步，不能认为已经获得完整的直播节奏控制。

该标志**持久化**，不是带超时的租约：插件退出后，模组独立驾驶在战斗外仍可能等候。
恢复独立驾驶时关闭直播模式并确认目标实例已同步，或将该实例的模组配置恢复为 false。
修改只同步当前连接的实例；其他游戏实例在下一次连接／切换时同步。

## 实机验收清单

离线单测验证计时、失效与候选边界，不能验证 Godot 页面、真实弹幕或语音队列。
更新安装并获得允许后，建议逐项检查：

- 关闭直播模式，原有奖励／商店／事件／休息行为不变。
- 开启随性档，确认模组同步成功；奖励展开不卡住，选牌页等待后才落子。
- 商店连续购买、事件翻页、休息 → 锻造选牌都有独立窗口，独立 mod 驾驶不会抢点。
- 低血量与高血量休息提示不同；内容只描述本次真实状态。
- 直播间有相关评论时尝试接话；没有评论／NEKO Live 未连接时不虚构观众。
- 等待中手动改选项、切页或进入战斗，不执行旧选择；暂停和显式执行行为符合预期。
- 对照三档的决策记录，认真保持原推荐，其他档可能尝试接近候选；战斗不被故意拖慢。
- 按语音延迟调整倍率，确认没有持续堆积过时解说。

该脚本拦截全部请求，只返回本地静态文件和模拟宿主结果，验证读取、未保存编辑保护、保存／重载、输入边界和
桌面／平板／手机布局。截图写到 `dist/livestream-ui-review`，不代表真实游戏或直播状态。
