# v0.8.3 — 插件与 NekoSpire 0.1.11

## 下载
- `sts2_autoplay.neko-plugin`：N.E.K.O 插件 0.8.3，由官方发布工作流构建并生成验证材料。
- `NekoSpire-0.1.11-windows.zip`：游戏 mod，包含 DLL、PCK、界面图片、对应源码与第三方许可。
- `.sha256`：mod 压缩包的 SHA-256 校验值。

## 修复与改进
- 修复静默、故障机器人、摄政旧模型的内容特征错位：补齐固定版本的 v0.111.0 内容目录，按特征名称映射权重，禁止未知顺序下的按位置补零。
- 检查目录大小与 SHA-256；缺失、损坏或旧推理进程无法验证对齐时，明确提示并回落到后备策略，不继续错误推理。
- 改进运行环境与模型下载的重试、镜像切换和错误提示；支持只补齐缺失或损坏的目录。
- 新增联机地图等待参数 `map_vote_wait_seconds`（默认 20 秒），可在插件面板配置。
- mod 增加箭矢状态、Quietus、旋律计数、FreeCardPower、UpgradeInternal 的游戏 API 兼容适配；本地补丁保留在 vendoring 脚本中。
- 同步 mod 健康接口报告的版本号为 0.1.11。

## 已安装用户升级
1. 更新插件；完全退出游戏后更新 mod。前置依赖为 RitsuLib >= 0.6.11。
2. 打开插件面板的「策略网络」页，补齐/修复运行环境。已有完整环境通常只需新增约 559 KiB 的旧版目录，无需重下模型或 PyTorch。
3. 重启插件拥有的策略推理进程；若是手动运行的旁路，请自行关闭旧进程并重新启动。旧进程会被新版插件拒绝。
4. 手动安装 mod 时，将压缩包中的 `nekospire` 文件夹放入游戏 `mods` 目录。不要与创意工坊订阅版重复启用。
