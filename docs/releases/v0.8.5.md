## 本次更新
- 联机「创建房间／继续存档」始终操作主机，不再随自动游玩的猫娘实例绑定切换；建房结果也读取主机状态，不覆盖猫娘快照。
- 支持复用已在主菜单或结算界面的猫娘进程加入下一局或恢复存档，重置上一局结束状态；先验证角色与重入能力，再执行握手，不误操作其他端口、不重复拉起进程。
- 保持直接创建新房间的行为；支持本地联机存档恢复。建房与恢复操作增加专用请求等待时间。
- 联机地图协作避免重复投票，跟随模式响应人类投票变化，正常地图等待不再误报卡住。
- 尖塔速报独立于弹幕开关，修复自动游玩关闭弹幕后速报被一起关闭，以及旧画面键错误丢弃新解说的问题；保留事实去重和共享冷却。
- 同步近期控制页、参数配置、历史页改进和静态状态快照；拆分 Python service/planner 与 C# 游戏服务大文件。
- 游戏提取立绘不再随插件分发，缺失时使用界面回退样式。

## 升级说明
1. 插件与 mod 必须一起升级。首次升级前退出主机与猫娘两个游戏进程，更新后重新启动，旧进程不会自动加载新 DLL。
2. 后续一局结束后无需为再次建房手动关闭猫娘；请先停止自动游玩，并确保猫娘已在主菜单或结算界面。
3. 安装并启用前置 RitsuLib >= 0.6.11。手动安装时将 ZIP 内 `nekospire` 文件夹放入游戏 `mods` 目录；不要同时启用本地版和工坊版。
4. 策略网络适配固定的 v0.114.0 编码器／目录，并非新训练权重。若从旧版本升级，请在「策略网络」页准备／修复运行环境，并重启推理旁路；完整已有模型不必重下。
