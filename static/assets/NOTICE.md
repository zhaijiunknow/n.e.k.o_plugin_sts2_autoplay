# Game artwork / 游戏美术来源

The six character portraits and spire-backdrop.webp are converted from the locally
installed Slay the Spire 2 game assets. Copyright remains with Mega Crit / their
respective owners. They are not original NekoSpire artwork and are not covered by
any source-code license in this repository. This is an unofficial companion UI.

sources.json records the original resource paths. tools/export_ui_art.py reproduces
the conversion from a user-supplied, locally owned game PCK; it does not download
or modify the game. No game fonts or other game resources are included.

These are the game's character-selection portraits, not newly drawn full-body art.
Before redistributing the artwork, confirm the applicable artwork permissions;
this UI change does not itself publish a release or upload Workshop content.
